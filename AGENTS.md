# PROJECT RULES
Stack: JavaScript on Node.js. No external dependencies.
Style: ES Modules; 2-space indent; camelCase for variables and functions, PastalCase for classes; single quote for strings; no semicolons at the end of each line.
Commands: npm install for setup, npm test to run the tests.
Never: install or use externel dependencies or libraries; adjust the test case to make a test pass.
